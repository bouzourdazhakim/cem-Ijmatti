إعدادات الربط السحابي والمزامنة

حالة الربط السحابي الحالية:

جاري تحميل إعدادات السحابة...

حول Pantry.dev:

مزود تخزين سحابي مجاني وموثوق. للبدء: سجل مجاناً في getpantry.cloud، واحصل على معرف Pantry ID وضعه بالأسفل.

حول Cloudinary كمزود مزامنة:

مجاني 25GB، بدون حدود طلبات — يحفظ بيانات الموقع في الملف العام cem_site_data.json ويقرأها من أي جهاز.

الكتابة فوق الملف الموجود تتطلب رفعاً موقّعاً: أضف API Key و API Secret من لوحة Cloudinary → Settings → API Keys (لن تعمل المزامنة بدونهما).

لرفع الصور/الملفات الجديدة في تبويب مركز رفع الصور يكفي الـ Upload Preset (Unsigned) دون مفاتيح.

حول KVDB.io:

مزود مجاني بحد 16KB لكل مفتاح. أنشئ Bucket عبر الأمر: curl -d 'email=you@email.com' https://kvdb.io ثم فعّل بريدك من kvdb.io/login قبل أن تعمل الكتابة.
